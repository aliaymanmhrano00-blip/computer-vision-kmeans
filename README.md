# K-Means Clustering باستخدام Python

تطبيق لخوارزمية **K-Means** على نقاط افتراضية ثنائية الأبعاد، مع تنفيذ الخوارزمية من الصفر باستخدام Python وNumPy، ثم رسم المجموعات والـ centroids باستخدام Matplotlib.

## الملفات

- `kmeans.py`: الكود الرئيسي.
- `requirements.txt`: المكتبات المطلوبة.
- `kmeans_result.png`: الرسم الناتج بعد التشغيل.

## التشغيل

1. ثبّت المكتبات:

```bash
pip install -r requirements.txt
```

2. شغّل البرنامج:

```bash
python kmeans.py
```

يمكن تغيير عدد المجموعات وعدد النقاط:

```bash
python kmeans.py --k 3 --points 50 --seed 42
```

## فكرة الخوارزمية

1. إنشاء نقاط افتراضية ثنائية الأبعاد.
2. اختيار `K` نقاط عشوائية لتكون مراكز ابتدائية.
3. حساب المسافة بين كل نقطة وكل مركز باستخدام Euclidean Distance.
4. إسناد كل نقطة إلى أقرب مركز.
5. تحديث كل مركز بحساب متوسط النقاط التابعة له.
6. تكرار الخطوتين السابقتين حتى تثبت المراكز أو نصل إلى الحد الأقصى للتكرارات.

## ملاحظات

- القيمة الافتراضية لـ `K` هي 3.
- يتم استخدام `seed=42` للحصول على نفس النتيجة عند كل تشغيل.
- البرنامج يتعامل مع حالة وجود مجموعة فارغة بإعادة اختيار مركز لها تلقائيًا.
